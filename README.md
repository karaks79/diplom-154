# VK Bot

Бот для поиска пользователей VK по заданным параметрам и сохранения понравившихся кандидатов в избранное.

## Описание проекта

Бот получает информацию о пользователе VK, который взаимодействует с ним, и выполняет поиск подходящих кандидатов.

При поиске учитываются следующие параметры:

* возраст пользователя;
* пол пользователя;
* город пользователя.

Правила поиска:

* возраст кандидата — от `MIN_AGE_DELTA` до `MAX_AGE_DELTA` лет меньше возраста пользователя;
* противоположный пол;
* тот же город;
* наличие фотографии профиля.

Для найденного кандидата бот получает фотографии профиля и выбирает три фотографии с наибольшим количеством отметок «Мне нравится».

Пользователь может:

* начать поиск;
* перейти к следующему кандидату;
* добавить кандидата в избранное;
* посмотреть список избранных кандидатов.

## Инструкция по использованию

После запуска бота откройте диалог с сообществом VK.

### 1. Начать поиск

Отправьте сообщение:

`Начать`

Бот определит ваш возраст, пол и город и выполнит поиск подходящих кандидатов.

После этого бот покажет первого найденного кандидата и три его наиболее популярных фотографии.

### 2. Посмотреть следующего кандидата

Отправьте:

`Следующий`

Бот покажет следующего кандидата из результатов поиска.

### 3. Добавить кандидата в избранное

Если кандидат понравился, отправьте:

`В избранное`

Кандидат будет сохранён в базе данных и появится в вашем списке избранного.

Повторное добавление одного и того же кандидата не создаёт дубликат.

### 4. Посмотреть избранное

Отправьте:

`Избранное`

Бот покажет список кандидатов, сохранённых в избранное.

### 5. Если кандидаты закончились

После просмотра всех найденных кандидатов бот сообщит, что кандидаты закончились.

Для нового поиска отправьте:

`Начать`

### Назначение модулей

`app/config.py`
Загрузка настроек и переменных окружения.

`app/vk.py`
Работа с VK API, получение информации о пользователях, отправка сообщений и создание клавиатуры.

`app/search.py`
Формирование параметров поиска, поиск кандидатов, получение фотографий и выбор трёх наиболее популярных фотографий.

`app/state.py`
Хранение текущего состояния поиска пользователя.

`app/database.py`
Подключение к PostgreSQL и работа с данными пользователей, кандидатов и избранного.

`app/main.py`
Основной цикл работы бота и обработка сообщений пользователя.

## База данных

Для проекта используется PostgreSQL.

Создаётся схема:

`netology_2026_diplom`

В схеме находятся три таблицы.

### users

Хранит пользователей бота.

Основные поля:

* `id` — внутренний идентификатор;
* `vk_id` — идентификатор пользователя VK;
* `first_name` — имя;
* `last_name` — фамилия.

### candidates

Хранит найденных кандидатов.

Основные поля:

* `id` — внутренний идентификатор;
* `vk_id` — идентификатор пользователя VK;
* `first_name` — имя;
* `last_name` — фамилия;
* `age` — возраст;
* `sex` — пол;
* `city_id` — идентификатор города VK;
* `city_name` — название города.

### favorites

Связывает пользователей бота с кандидатами, которых они добавили в избранное.

Основные поля:

* `id` — идентификатор записи;
* `user_id` — пользователь бота;
* `candidate_id` — кандидат.

Для предотвращения повторного добавления одного кандидата одному пользователю используется уникальное ограничение на пару `user_id` и `candidate_id`.

## Работа поиска

После команды `Начать` бот получает информацию о пользователе:

1. возраст;
2. пол;
3. город.

На основании этих данных формируются параметры поиска VK.

Бот ищет кандидатов, которые младше пользователя на `MIN_AGE_DELTA` - `MAX_AGE_DELTA` лет, имеют противоположный пол и находятся в том же городе.

Из результатов поиска исключается сам пользователь бота.

Для каждого найденного кандидата дополнительно запрашиваются фотографии профиля.

Из доступных фотографий выбираются три фотографии с наибольшим количеством отметок «Мне нравится».

После этого пользователю отправляется информация о кандидате:

* имя и фамилия;
* ссылка на профиль VK;
* три наиболее популярных фотографии.

## Хранение состояния поиска

Для каждого пользователя бота создаётся объект `SearchState`.

В нём хранятся:

* список найденных кандидатов;
* индекс текущего кандидата.

Это позволяет пользователю последовательно просматривать результаты поиска.
